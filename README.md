# ✈️ Financial Analysis — THYAO vs PGSUS

This project analyzes the financial performance of Turkish Airlines (THYAO) and Pegasus Airlines (PGSUS) using five-year financial data.

## 📊 Project Overview

The analysis focuses on key financial ratios to compare profitability, efficiency and risk structure between the two companies.

Key metrics analyzed:

- Revenue Growth
- Net Margin
- Return on Equity (ROE)
- Current Ratio
- Debt / Equity

The project includes data processing with Python and visualization using Matplotlib.

## 🧠 Key Insights

- THYAO demonstrates higher growth dynamics but also higher volatility.
- PGSUS shows more stable profitability trends after 2021.
- Leverage ratios indicate relatively higher financial risk for PGSUS.
